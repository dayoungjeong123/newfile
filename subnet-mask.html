1 IP 주소와 서브넷 마스크란?

IP 주소는 192.168.1.10처럼 점(.)으로 구분된 4개의 숫자(옥텟, octet)로 이루어져요. 각 옥텟은 0~255 사이의 값을 가지는데, 이는 8개의 비트(2진수 자리)로 표현되기 때문이에요. 즉 IP 주소 전체는 32비트로 이루어져 있습니다.

하나의 IP 주소는 사실 두 부분으로 나뉘어요: 네트워크 부분(어느 네트워크에 속하는지)과 호스트 부분(그 네트워크 안에서 어떤 기기인지). 문제는 IP 주소만 봐서는 어디까지가 네트워크이고 어디부터가 호스트인지 알 수 없다는 거예요. 이걸 알려주는 것이 바로 서브넷 마스크(Subnet Mask)입니다.

예를 들어 서브넷 마스크가 255.255.255.0이라면, 앞의 3개 옥텟(24비트)은 네트워크를, 마지막 1개 옥텟(8비트)은 그 네트워크 안의 호스트(기기)를 구분하는 데 사용돼요.

선생님 한마디

서브넷 마스크는 "이 IP 주소에서 어디까지가 동네(네트워크) 이름이고, 어디부터가 집(호스트) 번호인지" 알려주는 규칙이라고 생각하면 쉬워요. 같은 네트워크에 속한 기기끼리는 스위치나 공유기를 통해 바로 통신할 수 있지만, 다른 네트워크에 있는 기기와 통신하려면 라우터를 거쳐야 해요.

2 CIDR 표기법 (/24 같은 표기)

서브넷 마스크를 255.255.255.0처럼 매번 쓰기보다, 1의 개수만 세어서 /24처럼 표현하는 방법을 CIDR(사이더) 표기법이라고 해요. 192.168.1.10/24는 "192.168.1.10 주소이고, 앞의 24비트가 네트워크 부분"이라는 뜻입니다.

선생님 한마디

호스트 수를 구하는 공식은 2^(호스트 비트 수) - 2예요. 2를 빼는 이유는 호스트 부분이 전부 0인 주소(네트워크 주소)와 전부 1인 주소(브로드캐스트 주소)는 실제 기기에 할당할 수 없기 때문이에요.

3 서브넷 계산기 (직접 해보기)

IP 주소를 입력하고, CIDR을 고르거나 서브넷 마스크를 직접 입력하면 네트워크 주소, 브로드캐스트 주소, 사용 가능한 호스트 범위를 바로 계산해줘요.

# Python 코드 한 줄씩 실행 웹앱

파이썬 코드를 한 줄씩 실행하면서 변수 값 변화를 확인할 수 있는 교육용 웹앱입니다.

## 기능

- ✅ 진짜 파이썬 문법 지원 (Pyodide 기반)
- ✅ 한 줄씩 실행하며 변수 상태 확인
- ✅ 자동 순서도 생성
- ✅ 친절한 한국어 오류 설명 (교사 말풍선)

## 배포 방법

### 방법 1: GitHub Pages (추천 - 무료)

1. GitHub에 저장소 생성
2. 파일 업로드
3. Settings > Pages에서 배포 활성화

### 방법 2: Vercel (추천 - 무료, 간단)

1. [Vercel](https://vercel.com) 가입
2. 프로젝트 업로드
3. 자동 배포 완료

### 방법 3: Netlify (무료)

1. [Netlify](https://netlify.com) 가입
2. 프로젝트 드래그 앤 드롭
3. 즉시 배포 완료

## 로컬 실행

```bash
# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 사용 기술

- Pyodide (브라우저에서 파이썬 실행)
- Mermaid.js (순서도 생성)
- 순수 HTML/CSS/JavaScript
